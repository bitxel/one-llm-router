Operator notes

Shipping the same image twice?

Set ROUTER_DB_URL at process start and this form will show as managed externally. Same binary, different envs.

Change your mind later

Engine choice is not one-way. A CLI export/import ships with v0.2.0 to migrate between SQLite, Postgres, and MySQL.
